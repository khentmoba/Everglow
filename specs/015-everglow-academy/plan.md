## Summary

The **Everglow Academy** is a gamified learning feature integrated into the Everglow dashboard. It features a "Portal" card entrance, a central Hub for mode selection, a local "Solo Study" loop, and a real-time Firestore-backed "1v1 Challenge" mode. The technical approach leverages Firestore's `StreamBuilder` for instantaneous synchronization between players and a state-based game engine to handle matchmaking and point scoring.
