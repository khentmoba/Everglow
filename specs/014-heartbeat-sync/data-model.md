# Data Model: Heartbeat Sync

## UserMood (Collection: `moods`)

Represents a single emotional check-in from a user.

| Field | Type | Description |
|-------|------|-------------|
| `userId` | String | ID of the submitting user (e.g., 'clair', 'khent') |
| `moodScore` | int | Value from 1 (lowest) to 5 (highest) |
| `moodEmoji` | String | Character representation (e.g., '💙', '💖') |
| `timestamp` | DateTime | Server-side timestamp of submission |

### Validation Rules
- `moodScore` MUST be an integer between 1 and 5 inclusive.
- `userId` MUST match the authenticated user's ID.
- `timestamp` SHOULD be generated by the server (`FieldValue.serverTimestamp()`).

### Relationships
- Belongs to a **User** (via `userId`).
- Queried by **Partner** (to display status).

### State Transitions
1. **Unsubmitted**: User enters app, check-in missing for today.
2. **Submitting**: User selects mood, data persisted to Firestore.
3. **Synced**: Entry visible to partner in real-time.
