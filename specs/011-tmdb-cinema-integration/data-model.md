# Data Model: TMDB Cinema Integration

## MediaItem Entity

Represents a movie or TV show in the Everglow shared collection.

| Field | Type | Description |
|-------|------|-------------|
| `id` | String | Unique Firestore Document ID. |
| `tmdbId` | int | Unique ID from TMDB. |
| `title` | String | Title of the movie or name of the TV series. |
| `mediaType` | String | Either 'movie' or 'tv'. |
| `posterPath` | String | Full URL to the poster image. |
| `status` | String | 'to-watch' or 'watched'. |
| `addedAt` | DateTime | Timestamp when the item was added to Everglow. |

## Collection: `watch_list`

- **Document ID**: Auto-generated by Firestore.
- **Constraints**:
    - `tmdbId` should be unique within the user's collection to prevent duplicates.
    - `status` must be either 'to-watch' or 'watched'.
